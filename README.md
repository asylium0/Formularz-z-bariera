### Jaka jest różnica między tymi trzema opcjami?
- spread - rozstawia równo wszystkie elementy z uwzględnieniem ich wagi
- sread_inside - maksymalnie rozstawia skrajne elementy a na pozostałych robbi spread
- packed - zbija razem elementy i je środkuje
